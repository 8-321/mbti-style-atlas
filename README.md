# MBTI 影像风格档案馆 · STYLE ATLAS

把 4 套 MBTI 影像风格拆成可筛选、可播放、可复用的选型站：每套风格都给出视觉系统、声音节奏、叙事骨架、复刻公式和代表成片。

## 在线访问

GitHub Pages：`https://8-321.github.io/mbti-style-atlas/`

## 站点内容

- **4 套风格族**：暗室档案 / 萌猫寓言 / 木偶剧场 / 低多边形图鉴
- **5 条成片**：4 条风格主片 + 1 条萌猫长版
- **7 个交互区**：风格族、风格坐标、十六型选片表、选型器、全部样片、对照表、详情弹窗
- **16 型选片表**：每种类型给出推荐风格、一句理由，点开直达完整拆解
- **每套风格详情**：完整片、视觉系统、声音节奏、叙事骨架、复刻公式、可迁移 / 不要照抄、代表帧

## 本地预览

```powershell
cd mbti-style-atlas
python -m http.server 8099 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8099/`。

## 文件结构

```text
index.html                 页面结构
assets/
  styles.css               视觉系统与响应式
  data.js                  4 套风格 + 5 条成片的全部内容
  app.js                   渲染、筛选、选型器、弹窗
media/
  *.mp4                    720p 网页版成片
  posters/*.jpg            代表帧与视频封面
```

## 说明

- 视频为 720p H.264 + AAC，已开启 faststart，适合网页直接播放。
- 参考原片仅用于本地拉片学习，未包含在本仓库。
- 成片均为本项目重制版本。
